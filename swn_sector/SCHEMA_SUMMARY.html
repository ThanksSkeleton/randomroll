Extraction method and review status

extract_tables.mjs is a reproducible extraction script. It reads the local PDF with Poppler’s layout/bounding-box output, locates the 100 named tag cards, retains their source locators, and writes the three JSON table documents. It fails if a tag card does not expose all five prompt categories.

Automated checks performed: JSON parsing; 100 extracted tags; contiguous rolls 1–100; five prompt categories per tag; five world-attribute tables; and the expected roll-row counts. The next quality gate should review the JSON table cells against the rendered source pages before implementation.
